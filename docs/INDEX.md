# Documentation index

Single navigation entry for the phantom-training knowledge base. Each doc below
has one job; **status lives only in [`/ROADMAP.md`](../ROADMAP.md)**.

| Doc | What it is | Authority |
|---|---|---|
| [`/README.md`](../README.md) | Front door: positioning, niche, quickstart, links. | Entry point (no status) |
| [`/ROADMAP.md`](../ROADMAP.md) | Shipped / In progress / Planned-next, date-stamped and grounded in real commits. | **Status SSOT** |
| [`/DESIGN.md`](../DESIGN.md) | Design spec — the reframed "Agentic Training Ops loop" definition, phantom-mesh interfaces, MVP gate, deferred scope, risks. | Design spec |
| [`02-phantom-training.md`](02-phantom-training.md) | Sanitized master-plan spec: full competitor matrix, BIG-GOAL alignment, MVP scope, monetization, why M3-timed. | Design spec (master plan) |
| [`demo.cast`](demo.cast) | Self-hosted asciinema recording of the Tier-1 `--dry-run` plan. Play with `asciinema play docs/demo.cast`. | Artifact |
| [`_archive/`](_archive/) | Superseded / dated dev-logs, frozen with a tombstone. | Frozen history |

## Conventions

- **Status questions** → `/ROADMAP.md` only. No other doc should restate
  shipped/planned state.
- **Spec / design questions** → `DESIGN.md` (current reframe) and
  `02-phantom-training.md` (master-plan detail).
- **Historical "what shipped on date X"** → `_archive/`, but treat it as frozen;
  the live picture is always `/ROADMAP.md`.
